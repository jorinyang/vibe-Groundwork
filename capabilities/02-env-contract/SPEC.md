# 环境变量契约

## 为什么

缺一个变量，项目在本机能跑、到服务器就 500。报错位置通常在业务深处，离真正的原因很远。没有模板，换个人克隆下来不知道该配什么。

## 必须达到的行为

| # | 断言 | 怎么观测 | rigor |
|---|---|---|---|
| 1 | 存在环境变量模板 | 根目录有 `.env.example` / `.env.sample` | static |
| 2 | 模板覆盖代码引用 | 代码里 `process.env.X` / `os.environ["X"]` 的变量全部出现在模板 | static |
| 3 | 启动时校验 | 存在缺变量即抛错的校验入口 | static |

## 怎么验

```bash
node src/cli.ts check --path <项目> --only env-contract
```

## 常见抄错

| 抄法 | 为什么不算通过 |
|---|---|
| 模板写 `PORT=` 却漏了 `DB_PATH` | 代码里读到 undefined，启动才炸 |
| 启动时 `console.warn` 但不退出 | 警告没人看，等于没校验 |
| 把默认值写死在代码里 | 那是隐性配置，换环境就错 |
| 变量声明了但代码没读 | 不算问题，只提示，不判失败 |
